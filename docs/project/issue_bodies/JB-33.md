Question from BT: every company should post on Job Bank Canada - if not, we need to know why.

Facts so far: Job Bank posting is not mandatory for most employers (it is required for LMIA recruitment). The ESDC open dataset is monthly CSV (latest August 2026) with title, NOC, NAICS, location, salary, but employer name is not consistently present.

Scope:
1. Add a `channels` field per company (own ATS, Getro, LEDC, Job Bank, LinkedIn-via-sweep) so "not on Job Bank" is visible data.
2. Spike: is there a permitted live Job Bank access path (official feed/API, terms of use for search pages)? No scraping until terms are checked.
3. Use the monthly dataset for market numbers (e.g. NOC 21310 electrical and electronics engineers: postings, salary ranges by region).
