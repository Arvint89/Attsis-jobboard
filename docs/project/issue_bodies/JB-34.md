Multi-location postings get the wrong distance. `geo` treats "Austin, TX; Santa Clara, CA; Toronto, ON" as one place and picks the longest recognised city name (Santa Clara), so a role available in Toronto shows 3,480 km / ring 4 instead of 168 km / ring 2. Tenstorrent posts most roles this way; distance filter and distance sort hide them.

Fix: split on ";" / "|", compute distance for each part, use the part nearest the user's home for ring, km, map coords and country. Card shows nearest location + "+N more" (full list on hover).
